PERSONAL PORTFOLIO WEBSITE — Nishat Jamal Ashik
================================================

HOW TO OPEN
-----------
Open index.html in any browser (Chrome, Firefox, Edge).
No internet connection is needed: all CSS, JavaScript, jQuery
and images are stored locally inside this folder.

PAGES
-----
index.html     Home — introduction, skills table, project process
about.html     About — biography, education table, awards
projects.html  Projects — four projects with a jQuery filter
contact.html   Contact — contact links and a validated form
               (JavaScript validation + Ajax submission)

FILES
-----
css/style.css              One shared stylesheet for all pages
js/script.js               Menu, current-page highlight, mobile
                           menu, footer year, form validation + Ajax
js/jquery-3.7.1.min.js     jQuery library (used for the project filter)
images/                    Portrait and project photos

The assignment report (Portfolio_Assignment_Report.docx / .pdf)
explains the planning, code and testing of this website.
