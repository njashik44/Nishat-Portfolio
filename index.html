How I build a project

  1. Understand the problem and write down the requirements.
  2. Plan the design — pages, database tables or circuit diagram.
  3. Build a small working version first, then add features.
  4. Test each part and fix problems using logs and debugging.
  5. Show the final result and note what I would improve next time.
